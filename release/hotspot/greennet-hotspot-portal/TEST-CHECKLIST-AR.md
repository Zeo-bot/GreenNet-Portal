# قائمة اختبار بوابة GreenNet Hotspot

## الملفات

- [ ] `login.html`, `status.html`, `logout.html`, `error.html`.
- [ ] `alogin.html`, `redirect.html`, `api.json`, `md5.js`.
- [ ] تعمل ملفات CSS وJS والصورة من مسارات محلية.

## الهاتف

- [ ] العرض صالح على 320px دون تمرير أفقي.
- [ ] لوحة المفاتيح لا تغطي حقول الدخول.
- [ ] زر إظهار/إخفاء كلمة المرور يعمل.
- [ ] Enter يرسل النموذج مرة واحدة.
- [ ] حالة التحميل تمنع النقر المتكرر.
- [ ] نافذة captive portal تفتح الصفحة بوضوح.

## الكمبيوتر

- [ ] الحقول والأزرار قابلة للاستخدام باللوحة.
- [ ] focus واضح.
- [ ] لا توجد طلبات CDN أو خطوط خارجية.

## تسجيل الدخول

- [ ] HTTP-CHAP ينجح مع `md5.js`.
- [ ] PAP/HTTPS ينجح فقط إذا كان profile يفعّله.
- [ ] بيانات صحيحة تحول إلى الصفحة المطلوبة.
- [ ] بيانات خاطئة تعرض رسالة عربية.
- [ ] رابط التجربة لا يظهر إلا عندما `trial=yes`.
- [ ] لا تظهر كلمة المرور في URL أو السجل أو الصفحة.

## الحالة والخروج

- [ ] الاسم وIP وMAC والمدة والوقت المتبقي صحيحة.
- [ ] بيانات الرفع والتنزيل صحيحة.
- [ ] القيم المفقودة تظهر «غير متاح».
- [ ] تحديث الحالة لا يسبب وميضًا أو إرسالًا.
- [ ] قطع الاتصال يفتح `logout.html`.
- [ ] إعادة الدخول تعمل بعد الخروج.

## بوابة المشترك

- [ ] الرابط مخفي عندما `subscriberPortalUrl` فارغ.
- [ ] الرابط الصحيح يفتح `/login` على خادم GreenNet.
- [ ] walled garden يسمح بالمضيف عند الحاجة قبل الدخول.
- [ ] لا يوجد `localhost` أو عنوان تطوير.

## التراجع

- [ ] قيمة HTML Directory السابقة مسجلة.
- [ ] النسخة الأصلية من مجلد Hotspot محفوظة.
- [ ] يمكن إعادة profile إلى المجلد السابق دون حذف بيانات.
